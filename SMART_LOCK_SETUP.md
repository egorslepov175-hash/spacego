# Запуск SPACEGO Smart Lock — QR Edition

Плата пользователя: **ESP32‑2432S028R, встроенный TFT 240×320, 2.8″**. Сенсор не используется, клавиатуры и PIN на устройстве нет. Исходный вариант с внешним E‑Ink заменён после уточнения модели платы.

## Порядок первого запуска

1. Прошить обычную CYD сборкой `SPACEGO_QR_CYD_ILI9341_full.bin` с адреса 0x0. Для аппаратной ревизии ST7789 есть отдельный образ.
2. Подключить реле по схеме в инструкции. Используется **GPIO22**, а не GPIO32: GPIO32 у этой платы связан с контроллером сенсора. По умолчанию предусмотрен NPN/MOSFET-каскад для active-LOW реле 5 V.
3. Войти в кабинет владельца под аккаунтом, на котором создавался backend. Добавить устройство и получить код подключения на 15 минут.
4. Настроить плату через USB скриптом `tools/configure_device.py`: Wi‑Fi 2.4 GHz, пароль и код подключения. Секретный ключ устройство создаст само.
5. После появления QR отсканировать его телефоном. Войти в аккаунт арендатора и запросить бронирование конкретного устройства.
6. В кабинете владельца подтвердить бронь и фактическое получение оплаты. Интеграции с платёжным провайдером нет: пользователь не может сам пометить серверную бронь оплаченной.
7. В оплаченный подтверждённый период нажать «Открыть ворота». Сервер проверит доступ и связь с устройством, затем передаст подписанную команду с коротким сроком действия.

QR содержит только публичный ID устройства. Сканирование и просмотр ссылки не активируют реле. Локальные демоброни каталога не заменяют серверную авторизацию. Старые демоссылки с токенами больше не разрешают вход.

## Проверки

```sh
node --test test/domain.test.mjs test/access.test.mjs test/smart-locks.test.mjs
node --test lock-backend/test/api.test.mjs lock-backend/test/protocol.test.mjs
```

Автоматическая сборка обеих версий TFT выполняется GitHub Actions. В разделе Releases появляются полный образ, образ приложения, ZIP исходников и SHA‑256. Аппаратное срабатывание и полярность реле необходимо проверить на макете без подключённой нагрузки перед первым разрешённым открытием.
