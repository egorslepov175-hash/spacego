# SPACEGO

Сайт по опубликованному чату, предоставленному пользователем. Каталог аренды пространств в Новосибирске, адаптивный интерфейс, карта с ценами, избранное, бронирования, местная переписка, профиль и кабинет владельца.

## Запуск

Node.js 22+: `node preview.mjs`, затем `http://127.0.0.1:4173`.
Проверки расчётов и доступности: `node --test test/domain.test.mjs`.
Готовые статические файлы находятся в `dist/`, настройки публикации в `.openai/hosting.json`.

## GitHub Pages

Публикация настроена в `.github/workflows/pages.yml`. В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**. Отправка изменений в `main` или `master` запускает проверки бронирования и QR, затем публикует только папку `dist/`. Workflow также можно запустить вручную из **Actions**.

Ссылка на сайт появляется в успешно завершённой задаче публикации в окружении `github-pages`. Сайт поддерживает размещение в подпапке репозитория: ресурсы подключаются по относительным путям, навигация работает через `#`. Данные на новом домене сохраняются отдельно от локальной версии.

## Границы версии

Это работающий локальный прототип. Объявления и цены демонстрационные. Данные сохраняются в localStorage данного браузера и домена. Профиль не является серверной учётной записью; синхронизации между устройствами нет. Сообщения не отправляются другим людям. Платежи, возвраты, локальный доступ только имитируется. Реальные платёжный провайдер, сервер, уведомления и замки не подключены.

Карта загружается через Leaflet/OpenStreetMap. Адрес можно открыть в Яндекс Картах. Фотографии и их лицензии перечислены на странице `credits.html`.


## SPACEGO Smart Lock — QR Edition

Физический доступ реализован отдельной прошивкой для ESP32‑2432S028R и серверным API. На устройстве только TFT с публичным QR; клавиатуры и PIN нет. Серверные брони и разрешения не берутся из localStorage каталога.

Начните с [SMART_LOCK_SETUP.md](SMART_LOCK_SETUP.md). Полная прошивка и подключение — [firmware/SPACEGO_Smart_Lock_QR/README.md](firmware/SPACEGO_Smart_Lock_QR/README.md). Backend, миграции и описание протокола — [lock-backend/README.md](lock-backend/README.md). Готовые бинарные файлы собираются GitHub Actions и публикуются в Releases.

Проверки каталога: `node --test test/domain.test.mjs test/access.test.mjs test/smart-locks.test.mjs`. Проверки API: `node --test lock-backend/test/api.test.mjs lock-backend/test/protocol.test.mjs`.
